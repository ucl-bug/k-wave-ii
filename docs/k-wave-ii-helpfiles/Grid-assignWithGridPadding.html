assignWithGridPadding

Class: kwave.toolbox.Grid Package: kwave.toolbox

Pad an input matrix.

  • Input Arguments
  • Output Arguments
  • See Also

Syntax

matrix = assignWithGridPadding(obj, matrix)
matrix = assignWithGridPadding(obj, matrix, expansionValue)

Description

Pads an input matrix using expandMatrix to account for the gridPadding of the associated Grid object. For vector fields, each component of the vector field is padded independently.

Input Arguments

  • matrix - (numeric) Matrix to pad.
  • expansionValue - (numeric) Value to assign within grid expansion, passed to expandMatrix.

Output Arguments

  • matrix - (numeric) Padded matrix.
